# Yeji Park 개인 페이지

소개 문구, 연락처, 장소 사진, Bio, 프로젝트 내용은 `content.json`에서 수정합니다. 화면 모양은 `styles.css`, 동작은 `script.js`에 있습니다.

## 내용 바꾸기

- 이름, 소개글, 프로필 사진, 이메일, WhatsApp 번호, SNS 링크: `profile`
- 지도에 표시할 장소와 사진: `places`의 장소 항목 안에 `photos` 배열로 추가
- 학력과 경력: `bio` 배열에 기간과 내용을 추가
- 프로젝트: `projects` 배열에 제목, 설명, 연도, 배너 스타일을 추가

지도에는 각 장소의 첫 번째 사진이 미리보기로 표시됩니다. 같은 장소에 사진을 여러 장 추가하면 미리보기의 `+N` 표시로 장수를 확인하고, 사진을 눌러 열린 모달에서 화살표로 넘길 수 있습니다. WhatsApp 번호는 `+82 10-1234-5678`처럼 국제 형식으로 적으면 됩니다.

사이트 문구는 영어로 작성합니다. 직접 가진 사진은 저장소의 `assets` 폴더에 넣고 `./assets/파일명.jpg` 형식으로 경로를 적습니다.

`content.json`은 JSON 형식이므로 항목 사이에 쉼표를 넣고, 마지막 항목 뒤에는 쉼표를 넣지 않습니다. 변경 내용을 저장소에 커밋하고 푸시하면 GitHub Pages에 반영됩니다.
