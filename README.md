# Yeji Park 개인 페이지

페이지에 보이는 소개와 사진, 이력, 프로젝트는 `content.json`에서 수정합니다. 화면 모양은 `styles.css`, 동작은 `script.js`에 있습니다.

## 내용 바꾸기

- 이름과 소개글, 프로필 사진, 이메일, SNS 링크: `profile`
- 미로 사진과 유튜브 주소: `cat`
- 장소와 사진 추가: `places`의 장소 항목 안에 `photos` 배열로 추가
- 경력과 학력: `experience`, `education`
- 프로젝트: `projects`
- 화면에 나오는 섹션 이름과 버튼 문구: `ui`

한국어와 영어 문구는 `{ "en": "English", "ko": "한국어" }` 형식으로 작성합니다. 사진은 웹에서 열 수 있는 이미지 주소를 넣으면 되고, 직접 가진 사진은 저장소에 추가한 뒤 `./assets/파일명.jpg`처럼 적어도 됩니다.

`content.json`은 JSON 형식이라 항목 뒤에 쉼표를 빠뜨리거나 마지막 항목 뒤에 쉼표를 추가하지 않도록 주의하세요. 수정한 내용은 저장소에 커밋하고 푸시하면 GitHub Pages에 반영됩니다.
